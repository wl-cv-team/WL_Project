# 로드맵

순서와 의존성만 적습니다. 일정과 담당은 정하지 않았습니다. 목표 정의는 [vision.md](vision.md)를 봅니다.

## 현재 계획의 범위

저장소 뼈대, 데이터 이동과 사람 단위 split, 단계 간 약속 문서, 탐지(G1) 기준선. 아래 G2 이후는 이 계획에 포함하지 않습니다.

## 순서와 의존성

| 순서 | 목표 | 선행 조건 |
|---|---|---|
| 1 | G1 객체 탐지 품질 | 데이터 이동, split, 라벨 점검 |
| 2 | G2 바 경로 추적 | G1 |
| 3 | G3 구간 분할과 구간별 측정 | G1 (포즈 추정 포함, 모델은 실측 후 선택) |
| 4 | G4 전문가 라벨 수집 | G3의 구간 정의. 라벨 형식과 일정은 열린 질문 |
| 5 | G5 연구 질문 | G3, G4 |
| 병행 | G6 문헌 목록 | 없음 (`docs/literature/`) |
| 후순위 | G7 쓰임새 탐색 | G2~G5의 결과 |
