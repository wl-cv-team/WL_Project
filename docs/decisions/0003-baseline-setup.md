기록일: 2026-11-18. 상태: 도메인 담당(`scv0413`)이 이슈 #2와 PR #17에서 정한 내용을 반영했다. 근거와 논의는 각 댓글에 있다.

## 결정

| 항목 | 결정 | 출처 |
|---|---|---|
| 학습 구성 | 원판 있는 39장 + 원판 없는 6장 = 45장(8편). 사람 단위 분할을 유지한다. | #2 (2026-11-18) |
| 검증 구성 | 기존 검증 인원 6명·6편의 원판 있는 39장을 유지한다. 12편 전체를 학습에 넣지 않는다. | #2 (2026-11-18) |
| 빈 라벨 6장(`b05_sn_f_01`, `b06_sn_f_01`)의 용도 | "별도 오탐 점검용"에서 **학습용**으로 바꾼다. 분할 표에서 두 인원이 `train`이다. 이 6장에서의 예측 확인은 학습 데이터 점검이며 독립적인 오탐 평가로 보고하지 않는다. | #2 (2026-11-18) |
| 원판 없음 영상의 평가 | 학습에 쓰지 않은 별도 인원의 영상에서 라벨을 만들 때까지 **미평가**로 명시한다. 현재 검증 39장으로 원판 없는 영상의 성능을 일반화하지 않는다. | #2 (2026-11-18) |
| 학습용 프레임 이미지 | git 제외 로컬 폴더에 저장해도 된다. 같은 원본 영상과 라벨에서 같은 프레임을 만들도록 추출 코드를 저장소에서 공유한다. 생성한 이미지와 영상은 git, 노트북 출력, PR·이슈 첨부에 올리지 않는다. | #2 (2026-11-18) |
| 베이스라인 시작 | PR #16의 라벨이 `main`에 들어온 뒤 이 묶음으로 시작한다(2026-11-18 병합됨). 첫 결과를 보고 부족한 부분에 추가 라벨링을 한다. | #2, PR #17 (2026-11-18) |
| 첫 실행 | **fine-tuning 없이 COCO 사전학습 모델을 그대로 실행한다.** 원판 데이터로 학습하거나 epoch, 학습률 등을 조정하지 않는다. 결과를 같이 본 뒤 fine-tuning 여부와 다음 실험을 정한다. 앞서 요청한 fine-tuning 설정 제안(backbone 동결, epoch, 학습률, 배치)은 이 결과를 본 뒤로 미룬다. | #2 (2026-11-18 18:23 KST 정정, https://github.com/wl-cv-team/WL_Project/issues/2#issuecomment-6974354921) |
| 첫 실행의 비교 | YOLO26 → YOLO11 → YOLOv8을 같은 조건에서 실행하고 사용 가중치, 라이브러리 버전, 장치, 입력 크기, 추론 임계값을 기록한다. | #2 (2026-11-18) |
| COCO 출력의 취급 | 원래 COCO 클래스 이름을 유지하고, 실제로 어떤 물체를 탐지하는지와 실행 가능 여부, 추론 시간을 확인한다. 사람이 낸 박스 등 다른 클래스의 출력을 `plate`로 바꾸지 않는다. 이 결과를 원판 탐지 성능으로 보고하지 않고 원판 라벨 기준 평가와 구분한다. | #2 (2026-11-18), PR #17 |
| `plate` 경로의 검증 | PR #17의 `plate` 경로는 학습한 plate 가중치만 받는다. 이 검증을 무조건 지우지 않고, COCO 실행은 별도 실행 경로나 명시적 모드로 둔다. | #2 (2026-11-18) |
| 결과 보고 | 경계 기반 프레임 선정이라는 점, 학습 45장(있음 39·없음 6), 검증 39장, 그룹별 인원·영상·프레임 수, fps와 해상도, 실험 조건, 전체 대상·실제 평가·`N/A` 수와 제외 사유를 적는다. 검증 결과를 영상 전체 프레임의 성능으로 일반화하지 않는다. | #2, PR #17 (2026-11-18) |
| 공유 기록 | 설정과 수치·텍스트로 남긴다. 원본 영상, 얼굴이 담긴 프레임, 노트북 출력, 모델 가중치는 git, 이슈, PR 첨부에 올리지 않는다. 결과 이미지는 로컬 화면에서 확인한다. | #2 (2026-11-18) |

## 첫 실제 실행에서 확인할 것 (PR #17에서 요청)

- 입력 색상 순서(BGR 또는 RGB)
- 박스 좌표 변환(원본 영상 픽셀과 일치하는지)
- 학습 가중치 로딩(fine-tuning을 시작할 때)

## 아직 정해지지 않은 것

- fine-tuning 설정(backbone 동결, epoch, 학습률, 배치 크기, seed). COCO 사전학습 그대로 실행한 결과를 본 뒤 제안한다.
- 원판 없음 독립 검증용 별도 인원의 라벨
- 두 번째 라벨링(pass 2)의 사용 여부와 어느 pass를 정답으로 쓸지
