## 근거

- 기존 라벨은 형식 검사를 모두 통과했다(`artifacts/label_audit/label_audit.md`, 로컬 생성물). 기존 라벨의 기준이 문서로 남아 있지 않고, `c08_sn_f_01_frame_0106`의 박스가 원판 위에 있지 않은 것이 컨택트 시트에서 확인되었다.
- 라벨된 프레임은 7개 영상 150장이며, 사람 단위로 나누면 검증이 3명 안팎이다.

## 이 결정이 계획에 주는 영향

- 계획의 Task 6(평가)부터 Task 9는 새 원판 라벨이 있어야 실행 의미가 있다. 새 라벨이 나올 때까지 보류한다.
- Task 6b의 입력은 새 라벨로 바뀐다. 라벨 형식과 폴더 규칙은 새 라벨링 규칙(#2)이 정해진 뒤에 확정한다.
- 라벨링 작업(원판 박스 #2, 동작 단계 점 #8, 관절 좌표 #9)이 평가 작업보다 먼저 필요하다. 로드맵 순서는 #8 논의 후 갱신한다.
