# YOLO26 fine-tuning 前 원판 위치 기준선

프로젝트 루트에서 실행합니다.

```bash
uv run python scripts/run_coco_location_baseline.py
```

YOLO26n COCO 가중치, 입력 640, conf 0.25, 매칭 IoU 0.5로 검증 라벨만 사용합니다.
기존 39프레임을 대상으로 하며 실제 대상 수는 보고서에 기록합니다.
COCO 클래스 이름을 유지하고 모든 예측을 위치 후보로 일대일 매칭합니다.
원래 사람을 올바르게 탐지한 박스도 원판 정답과 매칭되지 않으면 이 평가에서는 FP입니다.
따라서 원판 클래스 인식 성능이나 COCO 성능으로 해석하지 않습니다.
원판 없는 독립 검증 자료는 아직 없으므로 해당 장면의 성능은 평가하지 않습니다.

결과는 Git 제외 폴더 `artifacts/coco_location/`의 `report.json`과 `predictions.csv`입니다.
이미지와 가중치를 출력 폴더에 저장하지 않습니다.
기존 보고서를 보존하려면 `--out-dir artifacts/coco_location/run2`처럼 다른 경로를 씁니다.
평가 대상/성공/N/A 수와 사유를 함께 확인하며, N/A는 지표 분모에서 제외됩니다.
경계 기반 프레임의 결과를 영상 전체로 일반화하지 않습니다.
fine-tuning 후에도 같은 프레임과 IoU·confidence 조건을 고정해 비교합니다.

## 첫 실행 결과 (2026-11-18)

검증 6명·6편·39프레임, 원판 정답 39개를 평가했습니다.
TP 11, FP 66, FN 28, 정밀도 14.29%, 재현율 28.21%,
프레임당 FP 1.69개, 평가 39프레임, N/A 0입니다.
정밀도는 모든 COCO 클래스를 후보로 센 결과이므로 원판 클래스 인식 정확도가 아닙니다.

환경: Python 3.12.13, ultralytics 8.4.202, torch 2.15.0,
opencv 5.0.0.93, macOS 15.7.4 arm64, 장치 MPS.
설정에 seed=0을 기록하지만 이 실행 경로는 별도로 난수 seed를 초기화하지 않습니다.
NMS 등 나머지 추론 설정은 해당 라이브러리 버전 기본값을 사용합니다.

이 변경은 PR #18의 COCO 실행 코드에 의존합니다.
